# A local Vite studio that draws every picture as code, lit by three.js

atelier is a Vite + React 19.3 app with Tailwind and `@ui/kit`, run on dima's mac only: no deploy, no auth, a small vite-side server for bakes and takes. Lit pieces are paper sheets on a three.js stage through `@react-three/fiber`; flat pieces are plain svg. Baked output goes through `sharp`, `@resvg/resvg-js` and `svgo`, and takes live as git-tracked folders. It was chosen because every picture must be seeded and reproducible — a take is recut and compared, never regenerated by chance — and because the loop (render, look beside the reference, revise) needs dima to see each change live.

## Considered options

- **an image model** — no picture comes from one. a model output cannot be recut from a seed or tweaked one setting at a time, and the reference bar we measured uses no library at all (`~/frame/docs/research/art-studio-tooling.md`).
- **babylon, playcanvas, pixi, p5, rive and the like** — same job as three.js with no react gain, or an editor in the loop; skipped in the tooling research.

## Consequences

- react stays below 19.4 while r3f's peer range stops there.
- the main checkout is served by launchd (`x-atelier-live`, `:5180`), so atelier has no desktop launch entry — the checker waives that row.
